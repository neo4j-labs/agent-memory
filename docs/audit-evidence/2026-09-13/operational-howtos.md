## Product gaps remaining, with source evidence

Documentation corrections do not close these runtime concerns:

- **Existing-entity ID on MERGE:** `memory/long_term.py:563–628` creates a fresh Entity then ignores write return rows; `graph/query_builder.py:270–285` MERGEs name+type and preserves the existing id. Batch docs explicitly read the persisted exact ID before dependent writes. Needs a product fix/tests if the SDK should return canonical persisted identity in every case.
- **Preference replacement ownership:** `memory/consolidation.py:241–269` scopes only `old` using user_identifier and searches replacement vectors without matching replacement ownership; mutations at approximately 295–309 apply that pair. Source-backed risk, not a live multi-tenant execution. Docs prohibit applying this primitive to a multi-user graph pending correction.
- **Vertex wrapper dimensions:** `llm/adapters/vertex_ai.py:66–124` stores wrapper `dimensions` but does not forward output_dimensionality when constructing the underlying embedder. `embeddings/vertex_ai.py:118–171` defaults to 768. Offline test demonstrates configured 1536 wrapper metadata with an underlying 768 result; docs constrain wrapper example to 768. No product change made.
- **Relationship attributes:** `memory/long_term.py:987–1048` accepts attributes into the return model but does not pass them to persistence; `graph/queries.py:343–355` stores the listed fields only. Batch relation examples now use supported confidence and source-message provenance. Python agent also documented this gap in core entity guidance.
- **Encryption integration:** `core/encryption.py` supplies only protocol and NoOp implementation, with no MemoryClient injection/wiring. Docs no longer describe an installed cipher/middleware.
- **No automatic retention controls:** consolidation archival explicitly requires ttl_days (`memory/consolidation.py:322–388`); marks archived fields, without automatic scheduling, hard deletion or retrieval exclusion. Documented behavior, not altered.

Validation limits: substitutes do not execute Cypher in Neo4j or establish real model extraction/retrieval quality, provider availability, service behavior or release artifact parity. Full graph migration is intentionally an application-owned all-layer backfill/maintenance task; the tested helper covers entities only. Root retains publication/release/live-service gates.
