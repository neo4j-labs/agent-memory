== Hosted memory with NAMS

anchor:_path_a_hosted_nams_fastest_start[]anchor:_1_get_an_api_key[]anchor:_3_first_operations[]anchor:_working_with_entities[]anchor:_storing_preferences[]anchor:_getting_context_for_llm_prompts[]

Use a workspace-bound API key from https://memory.neo4jlabs.com[the NAMS dashboard]. Keep it on the server and select the intended workspace before writing memory. See xref:reference/authentication.adoc[authentication and key categories].

* *Python:* xref:tutorials/nams-quickstart.adoc[store and retrieve hosted memory].
* *TypeScript:* xref:tutorials/hosted-quickstart-typescript.adoc[connect to hosted memory]. The current TypeScript package requires Node.js 22 or later; check example-specific engine requirements too.

Store the conversation ID returned by the service when you want to resume it. A matching user identifier alone does not resume a conversation. Preferences, facts and client-created relationships are not hosted REST operations; see xref:reference/backend-capabilities.adoc[the capability reference].

== Python with Neo4j Aura

anchor:_path_b_self_hosted_neo4j_bolt[]anchor:_install_with_extras[]anchor:_download_spacy_model[]anchor:_setting_up_neo4j[]anchor:_option_1_docker_recommended_for_development[]anchor:_option_2_neo4j_desktop[]anchor:_option_3_neo4j_auradb_cloud[]anchor:_connecting_to_neo4j[]anchor:_configuration_with_environment_variables[]

Use a dedicated AuraDB instance with the `bolt` backend when you need client-side extraction, preferences, facts, geospatial queries or custom write Cypher. Start with xref:tutorials/first-agent-memory.adoc#_step_2_set_up_neo4j[the Aura connection setup].

* xref:tutorials/first-agent-memory.adoc[Build your first memory example] provides one complete setup path.
* xref:tutorials/conversation-memory.adoc[Build a conversation application] continues into model use.
* xref:tutorials/anthropic-and-local-embeddings.adoc[Use Anthropic and local embeddings] teaches a different provider setup in its own lesson.

Provider dependencies are explicit extras. The Python `[all]` bundle does not include every local model package; install the extra named by the selected lesson rather than relying on packages already in your environment.

== Copy and run an example

anchor:_runnable_examples[]

The Python tutorials show every required local file alongside the published package install. Create the lesson folder, copy each complete program or helper into its labelled filename, and run the displayed commands. No code download is required. Start with xref:tutorials/first-agent-memory.adoc[the Aura lesson] or xref:tutorials/nams-quickstart.adoc[the NAMS lesson]. TypeScript source examples require building the SDK before installing their local `file:` dependency; follow xref:sdks/typescript.adoc[the TypeScript setup].

== Verify your first result

Finish the selected tutorial's storage/readback check before adding a framework or changing providers. When extraction is asynchronous, wait for the documented readiness condition before inspecting entities. If a step fails, keep its full error output and use xref:faq.adoc[the FAQ] and the relevant SDK troubleshooting guide.
