= CLI Reference
:page-product: agent-memory
:page-pagination:
:toclevels: 2

Command-line interface for neo4j-agent-memory extraction and schema management.

== Installation

Install with CLI extras:

[source,bash]
----
pip install "neo4j-agent-memory[cli]"
----

The `extract` command's default extractor is GLiNER2.5, so add the model extra
too:

[source,bash]
----
pip install "neo4j-agent-memory[cli,gliner2]"
----

== Commands

=== extract

Extract entities from text or files.

[source,bash]
----
neo4j-agent-memory extract [OPTIONS] TEXT
----

==== Arguments

[cols="1,3", options="header"]
|===
| Argument | Description

| `TEXT`
| Text to extract entities from. Use `-` for stdin.
|===

==== Options

[cols="2,1,3", options="header"]
|===
| Option | Default | Description

| `--file`, `-f`
| _none_
| Read text from a file instead

| `--format`
| `table`
| Output format: `table`, `json`, `jsonl`

| `--schema`
| _none_
| Path to an `EntitySchemaConfig` YAML file

| `--ontology`
| _none_
| Path to an ontology document (JSON or YAML) to extract against

| `--gliner-schema`
| _none_
| Built-in domain schema: `poleo`, `podcast`, `news`, `scientific`, `business`,
  `entertainment`, `medical`, `legal`

| `--entity-types`, `-e`
| _all_
| Entity types to extract (can repeat)

| `--extractor`
| `gliner`
| Extractor to use: `gliner` (GLiNER2.5), `llm`, `hybrid`

| `--model`
| _extractor default_
| Model for the GLiNER2.5 or LLM extractor (GLiNER2.5 default:
  `fastino/gliner2.5-base-v1`)

| `--relations` / `--no-relations`
| `--relations`
| Extract relations between entities

| `--preferences` / `--no-preferences`
| `--no-preferences`
| Extract preferences/sentiments (LLM extractor only)

| `--confidence-threshold`
| `0.5`
| Minimum confidence threshold (0.0-1.0)

| `--quiet`, `-q`
| `false`
| Suppress the progress spinner
|===

`--ontology`, `--schema` and `--entity-types` are alternatives for the same slot
and are consulted in that order.

==== Examples

[source,bash]
----
# Extract from text
neo4j-agent-memory extract "John Smith works at Acme Corp in New York"

# Extract from file
neo4j-agent-memory extract --file document.txt

# Pipe from stdin
echo "Sarah lives in London" | neo4j-agent-memory extract -

# Use specific extractor
neo4j-agent-memory extract --extractor llm "..."

# Filter entity types
neo4j-agent-memory extract -e Person -e Organization "..."

# JSON output
neo4j-agent-memory extract --format json "..."

# Use a built-in domain schema
neo4j-agent-memory extract --gliner-schema podcast "..."

# Use your own ontology (entity labels and typed relationships)
neo4j-agent-memory extract --ontology my-ontology.yaml "..."

# Entities only, on the small checkpoint
neo4j-agent-memory extract --model fastino/gliner2.5-small-v1 --no-relations "..."
----

==== Output Formats

*Table (default):*

[source]
----
                      Extracted Entities
┏━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━┳━━━━━━━━━━━━┳━━━━━━━━━━━━━━━━━━┓
┃ Type         ┃ Name         ┃ Confidence ┃ Attributes       ┃
┡━━━━━━━━━━━━━━╇━━━━━━━━━━━━━━╇━━━━━━━━━━━━╇━━━━━━━━━━━━━━━━━━┩
│ PERSON       │ John Smith   │       0.95 │ {"gliner2_label"…│
│ ORGANIZATION │ Acme Corp    │       0.92 │ {"gliner2_label"…│
│ LOCATION     │ New York     │       0.88 │ {"gliner2_label"…│
└──────────────┴──────────────┴────────────┴──────────────────┘
----

Relations and preferences print as further tables when the run produced any.

*JSON:*

[source,json]
----
{
  "entities": [
    {"type": "PERSON", "name": "John Smith", "confidence": 0.95, "attributes": {"gliner2_label": "person"}},
    {"type": "ORGANIZATION", "name": "Acme Corp", "confidence": 0.92, "attributes": {"gliner2_label": "organization"}}
  ],
  "relations": [
    {"source": "John Smith", "relation_type": "EMPLOYED_BY", "target": "Acme Corp", "confidence": 0.71, "attributes": {}}
  ],
  "preferences": [],
  "source_text": "John Smith works at Acme Corp in New York"
}
----

*JSON Lines:*

[source]
----
{"type": "entity", "data": {"type": "PERSON", "name": "John Smith", "confidence": 0.95, "attributes": {}}}
{"type": "entity", "data": {"type": "ORGANIZATION", "name": "Acme Corp", "confidence": 0.92, "attributes": {}}}
{"type": "relation", "data": {"source": "John Smith", "relation_type": "EMPLOYED_BY", "target": "Acme Corp", "confidence": 0.71}}
----

Each line is tagged with its `type` (`entity`, `relation` or `preference`), so a
stream can carry all three.

=== schemas

Manage entity extraction schemas stored in Neo4j.

==== schemas list

List all schemas in the database.

[source,bash]
----
neo4j-agent-memory schemas list [OPTIONS]
----

[cols="2,1,3", options="header"]
|===
| Option | Default | Description

| `--uri`
| `bolt://localhost:7687`
| Neo4j connection URI

| `--username`
| `neo4j`
| Neo4j username

| `--password`
| _required_
| Neo4j password

| `--format`
| `table`
| Output format: `table`, `json`
|===

==== schemas show

Show details of a specific schema.

[source,bash]
----
neo4j-agent-memory schemas show SCHEMA_NAME [OPTIONS]
----

[cols="2,1,3", options="header"]
|===
| Option | Default | Description

| `--version`
| _latest_
| Specific version to show

| `--format`
| `yaml`
| Output format: `yaml`, `json`
|===

==== schemas validate

Validate a schema file.

[source,bash]
----
neo4j-agent-memory schemas validate SCHEMA_FILE
----

==== Examples

[source,bash]
----
# List schemas
neo4j-agent-memory schemas list --password $NEO4J_PASSWORD

# Show schema details
neo4j-agent-memory schemas show medical --format yaml

# Validate schema file
neo4j-agent-memory schemas validate custom_schema.yaml
----

=== ontology

Validate and compile ontology documents. Ontology *management* (create, update,
activate, diff) lives on the Python API — see `client.ontology`.

==== ontology validate

[source,bash]
----
neo4j-agent-memory ontology validate FILE
----

Loads `FILE` (`.json`/`.yaml`) through `load_ontology`, so an `EntitySchemaConfig`
file is accepted and converted, then reports everything
`OntologyDocument.validate_structure()` finds: duplicate labels, relationship
endpoints that name no declared label, bad inverse pairs, and `pole_type` values
outside POLE+O. Exits `1` on any problem.

Output on success:

[source]
----
✓ Ontology 'POLE+O' is valid.
  Entity types: Person, Organization, Location, Event, Object
  Relationship types: KNOWS, ALIAS_OF, MEMBER_OF, EMPLOYED_BY, ...
  Relationship patterns: 70
----

==== ontology compile

[source,bash]
----
neo4j-agent-memory ontology compile FILE
----

Compiles the ontology into the GLiNER2.5 JointIE schema and prints it as JSON.
Useful while authoring: it shows exactly which entity labels and typed
relationships the model will decode against. Requires `gliner2`; without it the
command exits `1` with an install hint.

==== Examples

[source,bash]
----
# Check an ontology before loading it
neo4j-agent-memory ontology validate ontology.yaml

# See what the model will actually decode
neo4j-agent-memory ontology compile ontology.yaml | jq .
----

=== mcp serve

Start the MCP server for Claude Desktop and other MCP hosts.

[source,bash]
----
neo4j-agent-memory mcp serve [OPTIONS]
----

==== Options

[cols="1,1,3", options="header"]
|===
| Option                  | Default               | Description
| `--uri`                 | `bolt://localhost:7687`| Neo4j connection URI (env: `NEO4J_URI`).
| `--user`                | `neo4j`               | Neo4j username (env: `NEO4J_USER`).
| `--password`            | _required_            | Neo4j password (env: `NEO4J_PASSWORD`).
| `--database`            | `neo4j`               | Neo4j database name (env: `NEO4J_DATABASE`).
| `--transport`           | `stdio`               | MCP transport: `stdio` or `http` (Streamable HTTP; `streamable-http` is a synonym). `sse` is deprecated and serves Streamable HTTP with a warning.
| `--host`                | `127.0.0.1`           | Host for the HTTP transport (`0.0.0.0` to expose it).
| `--port`                | `8080`                | Port for the HTTP transport.
| `--profile`             | `extended`            | Tool profile: `core` (6 tools) or `extended` (16 tools).
| `--session-strategy`    | `per_conversation`    | `per_conversation`, `per_day`, or `persistent`.
| `--user-id`             | _none_                | User ID for `per_day`/`persistent` strategies (env: `MCP_USER_ID`).
| `--observation-threshold`| `30000`              | Token threshold for observational memory compression.
| `--no-auto-preferences` | _disabled_            | Disable automatic preference detection.
| `--llm`                 | _none_                | LLM provider string, e.g. `anthropic/claude-3-5-sonnet-latest` (env: `NAM_LLM`). See xref:how-to/bring-your-own-model.adoc[Bring Your Own Model].
| `--llm-api-key`         | _none_                | API key override for the LLM provider (env: `NAM_LLM_API_KEY`).
| `--llm-api-base`        | _none_                | Base URL override (vLLM, Ollama, internal endpoint).
| `--embedding`           | _none_                | Embedding provider string, e.g. `BAAI/bge-small-en-v1.5` (env: `NAM_EMBEDDING`).
| `--embedding-dimensions`| _none_                | Override embedding dimensions for unknown models.
|===

==== Examples

[source,bash]
----
# Default (OpenAI embeddings, OpenAI gpt-4o-mini extractor).
neo4j-agent-memory mcp serve --password mypw

# Anthropic + local sentence-transformers, no OpenAI dependency.
neo4j-agent-memory mcp serve \
  --password mypw \
  --llm anthropic/claude-3-5-sonnet-latest \
  --embedding BAAI/bge-small-en-v1.5

# Local vLLM endpoint via LiteLLM.
neo4j-agent-memory mcp serve \
  --password mypw \
  --llm openai/llama-3.3-70b-instruct \
  --llm-api-base https://llms.internal.corp/v1

# Core profile (fewer tools), per-day session strategy.
neo4j-agent-memory mcp serve \
  --password mypw \
  --profile core \
  --session-strategy per_day \
  --user-id alice

# Streamable HTTP, for a networked deployment (Cloud Run, Kubernetes).
# The MCP endpoint is POST/GET http://<host>:8080/mcp/
neo4j-agent-memory mcp serve \
  --password mypw \
  --transport http \
  --host 0.0.0.0 \
  --port 8080
----

NOTE: `--transport sse` is deprecated. The MCP specification replaced the legacy
HTTP+SSE transport with Streamable HTTP; the flag still starts a server but logs
a warning and serves Streamable HTTP at `/mcp/`. See
xref:reference/mcp-tools.adoc#_transports[Transports].

== Environment Variables

The CLI respects these environment variables:

[source,bash]
----
# Neo4j connection (avoids passing --password)
export NEO4J_URI=bolt://localhost:7687
export NEO4J_USER=neo4j
export NEO4J_PASSWORD=password

# OpenAI (for LLM extractor or OpenAI provider strings)
export OPENAI_API_KEY=sk-...

# provider configuration
export NAM_LLM=anthropic/claude-3-5-sonnet-latest
export NAM_LLM_API_KEY=$ANTHROPIC_API_KEY
export NAM_EMBEDDING=BAAI/bge-small-en-v1.5
----
