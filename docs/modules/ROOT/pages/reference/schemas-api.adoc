== SchemaManager persistence API (bolt)

The following methods belong to `neo4j_agent_memory.schema.SchemaManager`, constructed with a connected Neo4jClient. Its active schema version is persistence metadata; changing it does not reconfigure existing MemoryClient extractors. `load_schema` loads the active version; `load_schema_version` selects an explicit version.

=== save_schema

Save a schema to Neo4j.

// contract: schema/persistence.py:SchemaManager.save_schema
[source,python]
----
async def save_schema(
    schema: EntitySchemaConfig,
    *,
    created_by: str | None=None,
    set_active: bool=True,
) -> StoredSchema: ...
----

[cols="1,4",options="header"]
|===
| Parameter | Description
| `schema` | The EntitySchemaConfig to save
| `created_by` | Optional identifier for who created this schema
| `set_active` | Whether to set this as the active version (default True)
|===

// contract: schema/persistence.py:SchemaManager.ensure_schema_index
[source,python]
----
async def ensure_schema_index() -> None: ...
----

`StoredSchema` includes the stored record ID, name, version, active flag, creation timestamp, creator, and EntitySchemaConfig. Schema deletion removes schema records; it does not delete the memory entities previously extracted using them.
