= Environment Variables Reference
:page-product: agent-memory
:page-pagination:
:toclevels: 2

Complete reference for all environment variables supported by neo4j-agent-memory.

== Overview

Environment variables use the `NAM_` prefix (Neo4j Agent Memory) and follow a nested structure with double underscores (`__`) for sub-keys.

Example: `NAM_NEO4J__URI` maps to `settings.neo4j.uri`

== Provider strings

The MCP CLI also reads two top-level provider env vars that bypass the legacy nested structure:

[cols="2,1,3", options="header"]
|===
| Variable          | Type   | Description
| `NAM_LLM`         | string | LLM provider string, e.g. `anthropic/claude-3-5-sonnet-latest`. Resolved via `from_provider`.
| `NAM_LLM_API_KEY` | string | API key override for `NAM_LLM`.
| `NAM_EMBEDDING`   | string | Embedding provider string, e.g. `BAAI/bge-small-en-v1.5`.
|===

These are equivalent to the matching `--llm` / `--embedding` flags on `neo4j-agent-memory mcp serve`. See xref:how-to/bring-your-own-model.adoc[Bring Your Own Model].

== Resolution Configuration

[cols="2,1,1,3", options="header"]
|===
| Variable | Type | Default | Description

| `NAM_RESOLUTION__STRATEGY`
| str
| `composite`
| `none`, `exact`, `fuzzy`, `semantic`, `composite`. `composite` builds
  `OntologyResolver` on bolt.

| `NAM_RESOLUTION__EXACT_THRESHOLD`
| float
| `1.0`
| Exact-match threshold (`EXACT` strategy)

| `NAM_RESOLUTION__FUZZY_THRESHOLD`
| float
| `0.85`
| Fuzzy string matching threshold

| `NAM_RESOLUTION__SEMANTIC_THRESHOLD`
| float
| `0.8`
| Embedding similarity threshold (`SEMANTIC` strategy)

| `NAM_RESOLUTION__FUZZY_SCORER`
| str
| `token_sort_ratio`
| RapidFuzz scorer name

| `NAM_RESOLUTION__RESOLVE_ON_INGEST`
| bool
| `true`
| Resolve extracted mentions while storing a message (v0.7). The single opt-out
  for ingest-time resolution.

| `NAM_RESOLUTION__AUTO_MERGE_THRESHOLD`
| float
| `0.90`
| Merge a mention onto the match at or above this score. Per-type override:
  `EntityTypeDef.resolution_threshold`.

| `NAM_RESOLUTION__REVIEW_THRESHOLD`
| float
| `0.85`
| Store the mention plus a pending `SAME_AS` edge between this and the
  auto-merge line. Must be `<=` `AUTO_MERGE_THRESHOLD`.

| `NAM_RESOLUTION__CANDIDATE_LIMIT`
| int
| `12`
| Blocking candidates per mention and per bucket

| `NAM_RESOLUTION__USE_ALIAS_GAZETTEER`
| bool
| `true`
| Use the ontology's `aliases` as blocking keys and as a 1.0 match rule

| `NAM_RESOLUTION__USE_EMBEDDING_BLOCKING`
| bool
| `true`
| Also block via the entity vector index (needs an embedder)

| `NAM_RESOLUTION__CONTEXT_WINDOW_CHARS`
| int
| `90`
| Half-width of the mention context window used in scoring

| `NAM_RESOLUTION__SCOPE`
| str
| `global`
| `global` or `user`. `user` restricts candidates to entities the tenant has
  mentioned.
|===

== Deduplication Configuration

There is no `deduplication` settings section, and no `NAM_DEDUPLICATION__*`
variables — they are ignored if set. Deduplication thresholds live on
`ResolutionConfig` (`NAM_RESOLUTION__AUTO_MERGE_THRESHOLD` /
`NAM_RESOLUTION__REVIEW_THRESHOLD` above), which is what both the ingestion path
and `long_term.add_entity` use. `DeduplicationConfig` remains as a constructor
argument on `LongTermMemory` for code that builds the layer directly; derive it
with `DeduplicationConfig.from_resolution_config(settings.resolution)`.

== Example Configuration

[source,bash]
----
# Neo4j connection
export NAM_NEO4J__URI=bolt://localhost:7687
export NAM_NEO4J__USERNAME=neo4j
export NAM_NEO4J__PASSWORD=my-secure-password

# Embedding (OpenAI)
export OPENAI_API_KEY=sk-...

# Extraction pipeline
export NAM_EXTRACTION__ENABLE_SPACY=true
export NAM_EXTRACTION__ENABLE_GLINER=true
export NAM_EXTRACTION__GLINER_MODEL=fastino/gliner2.5-base-v1
export NAM_EXTRACTION__GLINER_SCHEMA=podcast

# Background enrichment
export NAM_ENRICHMENT__ENABLED=true
export NAM_ENRICHMENT__PROVIDERS='["wikimedia"]'

# Geocoding
export NAM_GEOCODING__ENABLED=true
export NAM_GEOCODING__PROVIDER=nominatim
----

== NAMS

The hosted-backend selection variables.

[cols="1,2,1",options="header"]
|===
| Variable | Purpose | Default

| `MEMORY_API_KEY`
| NAMS API key. When set and `NAM_BACKEND` is unspecified, the backend
defaults to NAMS. Falls back to bolt when unset.
| _unset_

| `MEMORY_ENDPOINT`
| NAMS endpoint base URL. REST mode when the URL contains `/v\d+`.
| `+https://memory.neo4jlabs.com/v1+`

| `MEMORY_WORKSPACE_ID`
| NAMS workspace id. Lifted into `NamsConfig.workspace_id` and sent as the
`X-Workspace-Id` header on every request. Required by header-scoped
deployments (e.g. staging); harmless on production (which encodes the
workspace in the API key).
| _unset_

| `NAM_BACKEND`
| Force the backend: `bolt` or `nams`. Overrides the
`MEMORY_API_KEY`-based default.
| _unset_ (auto-resolved)

| `NAM_NAMS__TIMEOUT`
| HTTP request timeout in seconds.
| `30.0`

| `NAM_NAMS__MAX_RETRIES`
| Retry budget for 429 / 5xx / network errors.
| `3`

| `NAM_NAMS__VALIDATE_ON_CONNECT`
| If `true`, `connect()` makes a fail-fast authenticated probe request.
| `true`

| `NAM_NAMS__TRANSPORT_MODE`
| Force wire protocol: `auto`, `rest`, or `bridge`.
| `auto`
|===

**Example:**

[source,bash]
----
export MEMORY_API_KEY=nams_xxxxxxxxxxxxxxxx

# Optional overrides:
export MEMORY_ENDPOINT=https://nams.internal/v1
export NAM_NAMS__TIMEOUT=60
----
