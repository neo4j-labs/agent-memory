== ExtractorBuilder

Build a local extractor from enabled stages. `build()` returns NoOpExtractor when no stage is enabled, the concrete extractor for one stage, or ExtractionPipeline for multiple stages.

[source,python]
----
from neo4j_agent_memory.extraction import ExtractorBuilder

extractor = (
    ExtractorBuilder()
    .with_spacy("en_core_web_sm")
    .with_gliner_schema("podcast", threshold=0.5)
    .with_llm_fallback("gpt-4o-mini")
    .merge_by_confidence()
    .build()
)
----

The union method is `merge_by_union()`. `with_schema(EntitySchemaConfig)` copies entity type names into extraction labels; it does not apply relation endpoints, properties, constraints, or indexes. Use the explicit schema/validation APIs for those purposes.

=== with_gliner

Add GLiNER2 extractor to pipeline with simple labels.

// contract: extraction/factory.py:ExtractorBuilder.with_gliner
[source,python]
----
def with_gliner(
    model: str | None=None,
    threshold: float=0.5,
    device: str='cpu',
    *,
    model_name: str | None=None,
) -> ExtractorBuilder: ...
----

[cols="1,4",options="header"]
|===
| Parameter | Description
| `model` | GLiNER model identifier (e.g. `gliner-community/gliner_medium-v2.5`).
| `threshold` | Confidence threshold.
| `device` | Inference device (`cpu` / `cuda` / `mps`).
| `model_name` | Alias for `model` (kept for compatibility with the CLI and older call sites).
|===

=== with_gliner_schema

Add GLiNER2 extractor with a domain schema for better accuracy.

// contract: extraction/factory.py:ExtractorBuilder.with_gliner_schema
[source,python]
----
def with_gliner_schema(
    schema_name: str,
    model: str='gliner-community/gliner_medium-v2.5',
    threshold: float=0.5,
    device: str='cpu',
) -> ExtractorBuilder: ...
----

[cols="1,4",options="header"]
|===
| Parameter | Description
| `schema_name` | Name of the schema (poleo, podcast, news, scientific, business, entertainment, medical, legal)
| `model` | GLiNER2 model to use
| `threshold` | Confidence threshold
| `device` | Device to run on (cpu, cuda, mps)
|===
