Reference for built-in domain schemas and custom schema creation. This page is a short overview and index; each subsystem has its own page.

== Overview

Domain schemas define entity types with descriptions that improve GLiNER zero-shot extraction accuracy. Each schema supplies domain-specific labels and descriptions; assess extraction quality on your own sample data.
