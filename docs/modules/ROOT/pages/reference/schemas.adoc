== Overview

Domain schemas define entity types with descriptions that improve GLiNER2.5 zero-shot extraction accuracy: the model reads each description as an annotation guideline. Each schema supplies domain-specific labels and descriptions; assess extraction quality on your own sample data.

A `DomainSchema` is a catalog: labels with descriptions and no endpoint typing. `DomainSchema.to_ontology()` converts one into an `OntologyDocument`, which is what the extractor compiles. Each built-in catalog has a matching ontology template of the same name (`neo4j_agent_memory.ontology.get_template`), and `GLiNER2Extractor.for_schema` and `ExtractorBuilder.with_gliner_schema` resolve names through it, so the `poleo`, `podcast` and `news` templates bring typed relationships as well as labels.
