The Antora authoring, validation, diagram and publication workflow is maintained in https://github.com/neo4j-labs/agent-memory/blob/main/docs/MAINTAINING.md[Maintain the documentation]. The local build output is `docs/build/site`; the preview server builds once and serves static files.

The repository's TypeDoc workflow regenerates API attachments for the labs-pages docs build. The external publishing owner must verify the accepted revision, public base path and redirects. No Vercel configuration or GitHub Pages deployment is supplied by this page.

Deploying an application built on the SDKs, rather than this documentation site? See xref:reference/deploy-an-application.adoc[].
