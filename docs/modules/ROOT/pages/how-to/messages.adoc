== Retrieve only the intended conversation

[WARNING]
====
`short_term.search_messages` accepts a `session_id` keyword, but on the current Bolt implementation the underlying Cypher (`SEARCH_MESSAGES_BY_EMBEDDING`) never filters on it, so results can cross sessions. Do not use it to enforce user isolation. Authorize the caller's session ID yourself before passing it to `get_conversation`. The example's semantic search is explicitly database-wide and runs only on the disposable example data.
====

`get_conversation` accepts `limit` and `since`; `limit=None` currently fetches at most 1,000 messages, then applies the timestamp filter in Python. For larger histories, specify the intended bound or implement a scoped Cypher pagination query. See xref:reference/api/short-term.adoc[exact message contracts].

== Choose the related operation

[cols="2,4",options="header"]
|===
|Task |Supported approach
|Bulk import |`add_messages_batch`; inspect returned IDs and progress callbacks. `bulk_add_messages` is a separate backend-dependent compatibility method.
|Discover a user's conversations |`list_conversations(user_identifier=...)`; this is association filtering, not caller authorization.
|Discover session identifiers |`list_sessions(prefix=..., limit=..., offset=...)`; a naming prefix is not access control.
|Generate a summary |`get_conversation_summary`; an explicit callable overrides the configured provider. There is no `generate_summary`/`get_summary` pair.
|Build a model request |Read the selected conversation and `get_preferences_for(user_identifier)` explicitly; see xref:tutorials/conversation-memory.adoc[the complete chatbot].
|Remove a session |`clear_session(session_id)` affects linked data; inspect its reference contract before deletion. There is no `delete_session` wrapper.
|===

Metadata filters apply according to the selected search method's contract. They do not turn a shared database into an authorization boundary. `get_context` can include global semantic matches; see xref:reference/backend-capabilities.adoc#scope[data scope].
