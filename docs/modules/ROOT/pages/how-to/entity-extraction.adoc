How to configure entity extraction pipelines to automatically build your context graph from conversations and documents.

image::diagrams/three-extraction-approaches.png[Three extraction approaches: spaCy, GLiNER2.5, and LLM, each with different speed/quality trade-offs,width=480,align=left]

== Prerequisites

* `neo4j-agent-memory` installed
* For GLiNER2.5 extraction: `pip install "neo4j-agent-memory[gliner2]"`
* For LLM extraction: OpenAI API key or compatible LLM

== Quick Start

Use the built-in POLE+O schema for general-purpose extraction:

[source,python]
----
from neo4j_agent_memory import MemoryClient, MemorySettings
from neo4j_agent_memory.extraction import GLiNER2Extractor

settings = MemorySettings(
    neo4j={"uri": "bolt://localhost:7687", "password": "password"}
)

client = MemoryClient(settings)

# Create extractor with the built-in POLE+O ontology
extractor = GLiNER2Extractor.for_poleo()

text = """
    Customer Jane Smith called about her order #12345 from Nike.
    She purchased Air Max 90 shoes last week from our Manhattan store.
    She mentioned she prefers next-day delivery for future orders.
"""

result = await extractor.extract(text)

for entity in result.entities:
    print(f"  {entity.name} ({entity.full_type}) - confidence: {entity.confidence:.2f}")

for relation in result.relations:
    print(f"  {relation.source} -[{relation.relation_type}]-> {relation.target}")
----

The first call downloads `fastino/gliner2.5-base-v1` (~407 MB) and caches it.

== Choosing an Extractor

[TIP]
====
*Which extractor should I use?*

* **spaCy only** — throughput > 1000 docs/s, common entity types (PERSON, ORG, GPE), no GPU needed, offline
* **GLiNER2.5** — domain-specific types *and* typed relations in one pass, no API cost, GPU recommended; *the right default for most use cases*
* **LLM** — complex or ambiguous text where accuracy is critical, and the only stage that extracts preferences; add as a fallback, not a first pass
====

== Multi-Stage Extraction Pipelines

Combine extractors for comprehensive extraction:

[source,python]
----
from neo4j_agent_memory.extraction import (
    ExtractionPipeline,
    GLiNER2Extractor,
    LLMEntityExtractor,
    MergeStrategy,
)
from neo4j_agent_memory.ontology import get_template

ontology = get_template("business")

# Stage 1: Fast local extraction, entities + typed relations
gliner = GLiNER2Extractor.for_ontology(ontology)

# Stage 2: LLM for refinement and preferences
llm = LLMEntityExtractor(
    model="gpt-4o-mini",
    extract_relations=True,
    ontology=ontology,
)

pipeline = ExtractionPipeline(
    stages=[gliner, llm],
    merge_strategy=MergeStrategy.CONFIDENCE,  # Keep highest confidence per entity
    ontology=ontology,                        # Drop relations the ontology forbids
)

result = await pipeline.extract(text)
----

Passing the same ontology to every stage is what keeps them consistent: it
becomes the JointIE schema for GLiNER2.5, the guideline block and relationship
catalogue in the LLM prompt, and the rulebook for the final validation step.

[TIP]
====
*Use LLM as a fallback, not a first pass.* Run GLiNER2.5 first — it handles most entities and the ontology's typed relations with no API cost. Route to the LLM only when confidence is below your threshold, when the text is ambiguous, or when you need preferences (no local model extracts those).
====

=== Conditional Pipeline

Apply different schemas based on conversation content:

[source,python]
----
from neo4j_agent_memory.extraction import (
    ConditionalPipeline,
    ExtractorStage,
    GLiNER2Extractor,
)

business = ExtractorStage(GLiNER2Extractor.for_schema("business"), name="business")
medical = ExtractorStage(GLiNER2Extractor.for_schema("medical"), name="medical")

pipeline = ConditionalPipeline(
    stages=[business, medical],
    conditions={
        # Stage name -> predicate over (text, previous_result)
        "business": lambda text, previous: "portfolio" in text.lower(),
        "medical": lambda text, previous: "diagnosis" in text.lower(),
    },
)

result = await pipeline.extract(text)
----

`conditions` maps a *stage name* to a callable receiving `(text, previous_result)`.
A stage with no entry always runs. Wrap extractors in `ExtractorStage` when you
need to name them — the default name is the class name, which is the same string
for two `GLiNER2Extractor` instances.

== Store Extracted Entities

=== Basic Storage

[source,python]
----
result = await extractor.extract(text)

for entity in result.entities:
    stored, _ = await client.long_term.add_entity(
        name=entity.name,
        entity_type=entity.type,
        subtype=entity.subtype,
        attributes={
            "confidence": entity.confidence,
            "extracted_at": datetime.now().isoformat(),
        },
    )
----

NOTE: When entities are extracted on the ingestion path (`add_message`,
`add_messages_batch`, `extract_entities_from_session`) this loop is not needed —
entities, `MENTIONS` links and typed `RELATED_TO` edges are written for you.

=== With Deduplication

Prevent duplicate nodes in your context graph. `DeduplicationConfig` is set on
the `LongTermMemory` instance, not per call; `add_entity()` takes a
`deduplicate: bool` to opt a single entity out.

[source,python]
----
from neo4j_agent_memory.memory import DeduplicationConfig, LongTermMemory

long_term = LongTermMemory(
    client=neo4j_client,
    embedder=embedder,
    deduplication=DeduplicationConfig(
        auto_merge_threshold=0.95,  # Auto-merge highly similar entities
        flag_threshold=0.85,        # Flag for review between 0.85-0.95
        use_fuzzy_matching=True,
        match_same_type_only=True,
    ),
)

for extracted in result.entities:
    entity, dedup_result = await long_term.add_entity(
        name=extracted.name,
        entity_type=extracted.type,
    )

    if dedup_result.action == "merged":
        print(f"Merged '{extracted.name}' with '{dedup_result.matched_entity_name}'")
    elif dedup_result.action == "flagged":
        print(f"Flagged '{extracted.name}' for review")
----

=== Validate Before Storing

[source,python]
----
for entity in result.entities:
    if entity.confidence < 0.6:
        continue
    if len(entity.name) < 2:
        continue

    stored, _ = await client.long_term.add_entity(
        name=entity.name,
        entity_type=entity.type,
    )
----

=== With Provenance Tracking

[source,python]
----
entity, _ = await client.long_term.add_entity(
    name=extracted.name,
    entity_type=extracted.type,
)

await client.long_term.link_entity_to_message(
    entity,
    message.id,
    confidence=extracted.confidence,
    start_pos=extracted.start_pos,
    end_pos=extracted.end_pos,
    context=extracted.context,
)

await client.long_term.link_entity_to_extractor(
    entity,
    extracted.extractor or "gliner2",   # GLiNER2Extractor.name
    confidence=extracted.confidence,
)
----

Record the model id and the extractor version alongside it when you register the
extractor explicitly:

[source,python]
----
await client.long_term.register_extractor(
    extractor.name,                 # "gliner2"
    version=extractor.version,      # the installed gliner2 version
    config={"model": extractor.model_id, "threshold": extractor.threshold},
)
----
