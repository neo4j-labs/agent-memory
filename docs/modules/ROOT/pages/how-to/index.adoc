== How-To Guide Philosophy

Each guide follows a consistent structure:

1. *Goal*: What you'll accomplish (one sentence)
2. *Prerequisites*: What you need before starting
3. *Steps*: Numbered, actionable instructions
4. *Verification*: How to confirm it worked
5. *See Also*: Related guides and reference material

If you're new to neo4j-agent-memory, start with the xref:tutorials/index.adoc[Tutorials] first.

For understanding the concepts behind these operations, see the xref:explanation/index.adoc[Explanation] section.

For complete API details and configuration options, see the xref:reference/index.adoc[Reference] section.
