= TypeScript framework integrations
:description: Pick a TypeScript agent framework integration for @neo4j-labs/agent-memory.

See also xref:how-to/integrations/index.adoc[the Python framework integrations index] for the equivalent guides in the Python SDK.

Find the right TypeScript integration for your agent framework, each backed by the same `MemoryClient`.

Prerequisites: a configured `MemoryClient` — see xref:sdks/typescript.adoc[the TypeScript SDK page] — and, for the hosted backend, NAMS credentials.

== Vercel AI SDK (TypeScript)

`agentMemoryMiddleware` injects three-tier context into each model call and
attempts to persist both the user's input and the assistant's response —
streamed or not. See xref:how-to/typescript/vercel-ai.adoc[Integrate with the Vercel AI SDK].

== LangChain JS (TypeScript)

`Neo4jChatMessageHistory` and `Neo4jEntityRetriever` supply framework-neutral
history and retrieval objects that you adapt to LangChain's APIs. See
xref:how-to/typescript/langchain.adoc[Integrate with LangChain JS].

== Mastra (TypeScript)

`Neo4jMastraMemory` is a thin thread-and-message-history adapter in Mastra's
vocabulary, driven alongside your agent rather than passed as its `memory`.
See xref:how-to/typescript/mastra.adoc[Store Mastra threads in NAMS].

== Strands Agents (TypeScript)

`Neo4jMemoryStore` is a Strands `MemoryStore`, and `connectMemoryToAgent`
wires session state and three-tier context injection into a Strands `Agent`
in one call. See xref:how-to/typescript/strands.adoc[Strands Agents (TypeScript)].

== Other languages

Agent Memory also ships clients for languages besides TypeScript.

* [[_langgraph_python]][[_pydanticai_python]]**Python** — LangGraph
  (`MemoryCheckpointSaver`) and PydanticAI (`MemoryToolset`,
  `inject_memory_context`) integrations are available through the hosted
  client (`neo4j_agent_memory_client`). For the self-hosted package's Python
  framework integrations, see xref:how-to/integrations/index.adoc[].
+
[source,python]
----
from neo4j_agent_memory_client import MemoryClient
from neo4j_agent_memory_client.integrations.langgraph import MemoryCheckpointSaver

client = MemoryClient(endpoint="https://memory.neo4jlabs.com/v1", api_key=...)
saver = MemoryCheckpointSaver(client)

graph = StateGraph(MyState)
graph.compile(checkpointer=saver)
----

* [[_semantic_kernel_c]]**C#** — `MemoryConnector` provides save/search and a
  `GetContextPrefixAsync` helper for Semantic Kernel functions:
+
[source,csharp]
----
using Neo4j.AgentMemory.Integrations.SemanticKernel;

var client = new MemoryClient(...);
var connector = new MemoryConnector(client);

await connector.SaveAsync(collection: "concept", id: "ddd", text: "Domain-Driven Design");
var hits = await connector.SearchAsync("microservice patterns", limit: 5);
var contextPrefix = await connector.GetContextPrefixAsync(conversationId);
----

* [[_ellmer]]**R** — `register_memory_tools(client)` returns a list of
  https://ellmer.tidyverse.org/[ellmer] `tool()` definitions wrapping all 12
  memory tools:
+
[source,r]
----
library(neo4j.memory)
library(ellmer)

client <- MemoryClient$new(endpoint = "...", api_key = ...)
tools <- register_memory_tools(client)

chat <- chat_openai(model = "gpt-4o")
for (t in tools) chat$register_tool(t$name, t$description, t$handler)
----
