= TypeScript SDK — @neo4j-labs/agent-memory
:description: Install, configure, and use the TypeScript SDK for Neo4j Agent Memory.

The TypeScript SDK is a thin HTTP client over the
xref:reference/rest-api.adoc[NAMS] hosted service. It runs on Node 22+,
Bun, Deno, Cloudflare Workers, and Vercel Edge.

include::partial$labs-disclaimer.adoc[]

== Install

[source,bash]
----
npm install @neo4j-labs/agent-memory@0.5.0
# or
pnpm add @neo4j-labs/agent-memory@0.5.0
bun add @neo4j-labs/agent-memory@0.5.0
----

Requires Node.js 22 or newer.

The package declares several optional peer dependencies, each needed only
for one integration: `@ai-sdk/provider` for the Vercel AI SDK middleware
types, `zod` and `@modelcontextprotocol/sdk` for `mcp/register`,
`@strands-agents/sdk` for the AWS Strands integration, and
`@opentelemetry/api` for tracing. Install only the ones your app uses.

== Quick start

Get an API key from link:https://memory.neo4jlabs.com[memory.neo4jlabs.com],
set `MEMORY_API_KEY`, then:

[source,typescript]
----
import { MemoryClient } from "@neo4j-labs/agent-memory";

const client = new MemoryClient();

const conv = await client.shortTerm.createConversation({ userId: "alice" });
await client.shortTerm.addMessage(conv.id, "user", "Hello!");

const entity = await client.longTerm.addEntity("Alice Johnson", "person", {
  description: "Software engineer working on graph memory.",
});

const ctx = await client.shortTerm.getContext(conv.id);
console.log(ctx.recentMessages, ctx.observations, ctx.reflections);
----

For edge runtimes (Cloudflare Workers, Vercel Edge), pass the API key
explicitly — see xref:how-to/typescript/edge-runtime.adoc[Edge Runtime].

== Looking for the Python SDK?

See xref:sdks/python.adoc[Python SDK]. The two SDKs share the same memory
model and back onto the same NAMS service. Mixed Python + TypeScript agents
can read and write the same memory.

== Runnable examples

link:https://github.com/neo4j-labs/agent-memory/tree/main/typescript/examples[`typescript/examples/`] holds ten examples. Start
with link:https://github.com/neo4j-labs/agent-memory/tree/main/typescript/examples/nextjs-memory-chat[`nextjs-memory-chat/`] —
the flagship full-stack demo: a Next.js 16 App Router assistant on hosted NAMS
with a live entity-graph rail, an extraction-status badge and a reasoning-trace
drawer. See xref:how-to/typescript/nextjs-memory-chat.adoc[the task-oriented guide]
for the four decisions behind it, or clone the example directly. The CI example matrix checks source compatibility with mocked services.
The eve commerce demo currently has unsupported hosted preference/fact paths;
see its README before using it as a deployment example. Offline checks do not
prove npm artifact availability or live-service behavior.
