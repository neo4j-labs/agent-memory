Create a local folder and virtual environment for this lesson. The commands reuse an existing environment without changing its files:

[source,bash]
----
mkdir -p ~/agent-memory-tutorials
cd ~/agent-memory-tutorials
if [ -e .venv ]; then
  printf '%s\n' 'Using the existing virtual environment.'
else
  python3 -m venv .venv
fi
source .venv/bin/activate
----
