These are the maintained method names on each SDK's client (`client.<layer>` in Python, `client.<camelCaseLayer>` in TypeScript), not a support matrix — the TypeScript SDK talks to the hosted NAMS REST backend only, so confirm an operation is exposed there in xref:reference/backend-capabilities.adoc[backend capabilities] before assuming parity with a Bolt-connected Python client.
