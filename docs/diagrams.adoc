= Diagram Inventory
:description: Catalog of all ASCII diagrams in the repository with their Excalidraw status
:keywords: diagrams, excalidraw, ascii-art, documentation

This page catalogs all ASCII art diagrams found in the repository and tracks their conversion to Excalidraw format.

== Overview

The documentation uses Excalidraw diagrams to visualize:

* **Architecture**: System components and their relationships
* **Pipelines**: Data flow and processing stages
* **Graph Schemas**: Neo4j node types and relationships (Cypher notation)
* **Memory Types**: Short-term, long-term, and reasoning memory structures

=== Diagram Workflow

[source,bash]
----
# List all diagram placeholders in documentation
make docs-diagrams-list

# Check status of diagrams (which are implemented, missing, etc.)
make docs-diagrams-status

# Show only missing diagrams that need to be created
make docs-diagrams-missing

# Generate Excalidraw conversion prompts
make docs-diagrams-generate

# Add image references to source files
make docs-diagrams-add-refs
----

=== File Locations

* **Excalidraw JSON**: `docs/assets/images/diagrams/excalidraw/{slug}.excalidraw`
* **Exported PNG**: `docs/assets/images/diagrams/{slug}.png`

== Creating New Diagrams

To create a new Excalidraw diagram:

1. Identify the ASCII art diagram in the source file
2. Use the `docs-excalidraw` Claude skill to generate JSON
3. Follow the Neo4j brand color palette above
4. Save to `docs/assets/images/diagrams/excalidraw/{slug}.excalidraw`
5. Export PNG from https://excalidraw.com
6. Run `make docs-diagrams-add-refs` to update source files
